This revision stops treating three production-build facts as development
residue: a react-router 7.x source-map path under dist/development (the
package routes every consumer there; its production folder differs by one
warnings flag), a http://localhost literal in a library URL fallback or an
app's own hostname blocklist, and the telemetry.global block that Webflow CLI
2.3.0 and earlier write into webflow.json. A development-build finding now
needs a marker that differs between the dependency's development and
production output. The telemetry block is packaging hygiene: strip it or
upgrade the CLI.

The token and scope authority classification from the 2026-08-27 revision is
unchanged.

and the production App submission form on 2026-09-16. Public documentation and

before reuse.
